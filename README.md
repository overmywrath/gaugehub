# gaugehub

> a universal roblox ai

**gaugehub**, also known as **ayami**, is a private, friends-only Roblox AI built around intelligent game utilities, automation, and an integrated AI assistant.

## Overview

gaugehub is designed to work across supported Roblox experiences while keeping its interface and AI accessible from a single hub.

Currently supported:

* Total Roblox Drama — Movies
* Total Roblox Drama — Expedition
* Total Roblox Drama — Camp

More experiences may be supported in the future.

## AI

The main focus of gaugehub is its built-in AI.

Instead of manually configuring every feature, you can talk directly to the AI and describe what you want. The AI is designed to assist with creating and using exploit-oriented features within supported experiences.

For example:

```text
> make me a player tracker
> add an esp for contestants
> teleport me to the nearest player
> create a feature that automatically collects items
```

The goal is to make feature creation conversational rather than requiring users to manually configure everything.

## Open Source

All of gaugehub's features are **open source**.

The feature implementations and supporting code are available for anyone to inspect, modify, and learn from.

The **gaugehub AI source code will remain closed source** and will not be publicly released.

This means the feature layer is open while the underlying AI implementation remains proprietary to gaugehub.

## Private Access

gaugehub is **friends-only**.

There is no public registration or open whitelist. Access is manually given to friends and trusted users.

This keeps gaugehub private and allows access to be controlled by the developers.
